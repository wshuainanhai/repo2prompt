# repo2prompt

> 把任意代码仓库，一键打包成「喂给 AI 刚刚好」的上下文。

[![PyPI version](https://img.shields.io/pypi/v/repo2prompt.svg)](https://pypi.org/project/repo2prompt/)
[![Python versions](https://img.shields.io/pypi/pyversions/repo2prompt.svg)](https://pypi.org/project/repo2prompt/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/YOUR_GITHUB_USERNAME/repo2prompt?style=social)](https://github.com/YOUR_GITHUB_USERNAME/repo2prompt)

**repo2prompt** 是一个零配置的命令行工具：读你的项目目录，自动生成一份 Markdown 文档，包含**目录树 + 每个文件的内容 + Token 估算**，并自动跳过 `.gitignore`、二进制文件和大文件。把这份文档丢给 Claude / ChatGPT / Gemini，就能让它「看懂」整个仓库，用来写 README、做 code review、生成 RAG 知识库、做需求分析都超好用。

---

## ✨ 特性

- 🌳 **目录树**：一眼看清项目结构
- 📄 **完整文件内容**：按语言高亮，自动带路径标记
- 🔢 **Token 估算**：内置 `tiktoken`（装了就用），否则用字符启发式估算，帮你控制上下文长度
- 🚫 **自动过滤**：尊重 `.gitignore`，跳过 `node_modules`、`.venv`、`__pycache__`、图片/音频等二进制、超大文件
- 🎯 **灵活筛选**：`--include` / `--exclude` 按 glob 精确控制
- 💡 **预算模式**：`--max-tokens` 软上限，超出自动裁剪，避免刷爆上下文
- 📋 **剪贴板 / 文件输出**：`--copy` 直接复制，`-o` 写文件
- 🪶 **零重型依赖**：核心只依赖纯 Python 的 `pathspec`

## 📦 安装

```bash
pip install repo2prompt
```

或从源码安装（可编辑模式，方便开发）：

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/repo2prompt.git
cd repo2prompt
pip install -e .
```

> 想要更精准的 Token 统计？再装一个 `pip install tiktoken` 即可。

## 🚀 使用

把当前目录打包并打印到终端：

```bash
repo2prompt .
```

写到文件（最常用）：

```bash
repo2prompt . -o context.prompt.md
```

只打包 Python 文件：

```bash
repo2prompt . --include "*.py"
```

排除测试目录、控制上下文预算：

```bash
repo2prompt . --exclude "tests/*" --max-tokens 50000 -o ctx.md
```

复制结果到剪贴板，直接粘进聊天框：

```bash
repo2prompt . --copy
```

只看会包含哪些文件（不生成内容）：

```bash
repo2prompt . --list
```

输出统计 JSON（方便接 CI / 脚本）：

```bash
repo2prompt . --json
```

## ⚙️ 命令行参数

| 参数 | 说明 |
| --- | --- |
| `path` | 仓库路径，默认当前目录 |
| `-o, --output` | 输出到文件而非 stdout |
| `-i, --include` | 仅包含匹配 glob 的文件（可多次） |
| `-x, --exclude` | 排除匹配 glob 的文件（可多次） |
| `--no-gitignore` | 不应用 `.gitignore` 规则 |
| `--no-tree` | 不生成目录树 |
| `--no-content` | 只输出目录树 + 文件列表（不含内容） |
| `--max-tokens` | Token 软预算（默认 200,000） |
| `--max-file-chars` | 跳过超过该字符数的文件（默认 200,000） |
| `--model` | tiktoken 模型名（若已安装） |
| `--copy` | 复制到剪贴板（需 `pyperclip`） |
| `--json` | 以 JSON 输出统计信息 |
| `--list` | 只列出将被包含的文件并退出 |

## 🧩 典型场景

- **写项目文档 / README**：把仓库打包给 AI，让它基于真实代码生成文档
- **Code Review**：把改动 + 相关文件一起喂给 AI，得到精准 review
- **构建 RAG 知识库**：先 `repo2prompt . -o ctx.md`，再切分入库
- **需求 / 架构分析**：让 AI 在「看懂全貌」的前提下给建议

# repo2prompt (English)

Pack any repository into clean, AI-friendly context: a directory tree + every
file's contents + token estimates, with `.gitignore`/binary/large-file
filtering built in. Pipe the result into Claude / ChatGPT / Gemini for README
generation, code review, RAG, or architecture analysis.

## Install

```bash
pip install repo2prompt
```

## Quick start

```bash
repo2prompt . -o context.prompt.md        # pack cwd into a file
repo2prompt . --include "*.py"            # only Python files
repo2prompt . --exclude "tests/*" --max-tokens 50000
repo2prompt . --copy                       # copy to clipboard
repo2prompt . --json                       # stats as JSON
```

## Why

When you ask an LLM to understand a codebase, the hard part is getting the
right files in front of it. `repo2prompt` does that in one command: respects
`.gitignore`, skips binaries and huge files, estimates tokens, and trims to a
budget so you never blow past the context window.
